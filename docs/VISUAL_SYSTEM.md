# Visual system — v0.3.2

- Geographic pages use contextual landscape palettes, atmospheric light and abstract landform geometry.
- All 22 atlas tiles and 14 location pages inherit the same visual tokens and responsive components.
- No invented tribal symbols, sacred designs, regalia or community-specific patterns are used.
- Future artwork must include creator, nation/community attribution where appropriate, permission, license and source.
- Respect reduced-motion and keyboard focus. Avoid claiming that palette choices represent Indigenous identity.
